# IF3170_G12_YuzukiAkatsukiMilikKita

Tugas Besar 2 IF3170 Inteligensi Artifisial: prediksi pembatalan pesanan penginapan dengan supervised learning.

## Struktur

- `src/` : kode program (satu file per model)
- `docs/` : laporan (PDF)
- `output/` : hasil submission dan model
- `data/` : dataset dari Kaggle (tidak di-commit)

## Setup

```
pip install -r requirements.txt
```

Letakkan `train.csv` dan `test.csv` di folder `data/`.
